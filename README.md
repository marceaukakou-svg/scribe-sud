# scribe-sud
L’École Nouvelle d’Égyptologie (ENE) se distingue, par une approche résolument innovante de l’étude des hiéroglyphes, fondée sur deux principes : Réhabilitation des systèmes phonogrammiques originels (dont l’aibôcôdère akan/agnî) est le principe et par l'intégration des données linguistiques africaines dans l’analyse des textes égyptiens.
